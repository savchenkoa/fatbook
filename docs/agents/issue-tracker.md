# Issue tracker

Use Linear MCP for the Fatbook team in the Sketchyy workspace. GitHub hosts the
repository; project work is tracked in Linear.

Before implementation, find the issue for the requested work or create one when
none exists. Use its identifier (`FAT-…`) in commit messages. Follow the status
and Git workflow in the root `AGENTS.md`.

For specs and task breakdowns, create Linear issues with self-contained
requirements and acceptance criteria. Record dependencies using Linear's native
blocking relationships. Reuse existing labels when applicable.

For roadmap work, read the Linear document
[Fatbook — Roadmap](https://linear.app/sketchyy/document/fatbook-roadmap-3acdfae71c0b).

If Linear MCP is unavailable, finish independent local work and report the
pending tracker actions. Keep issue creation and status updates pending until
the connection is available.
