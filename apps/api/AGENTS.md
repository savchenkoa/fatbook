# Go API

## Пустые строки

- Разделяй объявления функций, методов и типов одной пустой строкой, включая однострочные объявления. Комментарий к объявлению оставляй непосредственно над ним.
- Внутри функций разделяй одной пустой строкой смысловые этапы: проверку входных данных, подготовку ресурсов, выполнение операции и формирование результата.
- Держи вызов и проверку его ошибки вместе, без пустой строки между ними. Последовательные действия одного этапа также оставляй вместе.
- Перед завершением работы проверяй разделение блоков в изменённом коде вручную: прохождение `gofmt` само по себе не обеспечивает эти пустые строки.
